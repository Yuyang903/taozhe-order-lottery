享乐派App_v1.0 产品需求文档 (PRD)

产品名称：享乐派

文档版本：v1.0

编写日期：2024-03-27

1. 产品概述

享乐派App_v1.0 是一款专注于音乐实体专辑数字化体验与粉丝社区互动的移动端应用。用户可以通过 NFC 或扫描二维码将购买的实体专辑绑定至 App，获取专属的数字专辑内容（包括音乐、MV、电子写真、数字小卡、专属徽章等），并在专属的专辑社区中与其他粉丝进行互动。

2. 核心概念

在使用本产品前，需明确以下核心资产与权益概念：

  • 1. 收藏：用户通过绑定实体专辑获取的数字资产合集。
    • 1-1. 内容类：包含音乐、MV、写真等数字内容。
      • 1-1-1. 音乐：专辑内的无损音频资源。
      • 1-1-2. MV：专属的音乐录影带或花絮视频。
      • 1-1-3. 写真：高清电子版画册或艺人照片。
    • 1-2. 增值类：具有收藏与展示价值的数字周边。
      • 1-2-1. 小卡：随实体专辑附赠或通过盲盒抽取的数字收藏卡片。
      • 1-2-2. 徽章：用户完成特定条件（如绑定、活跃等）后获得的数字荣誉标识。
  • 2. 权益：用户持有特定数字资产后所解锁的附加福利，包括持续发布的各种互动类的线上线下活动（如专属社区发帖权限、线下活动优先购票权等）。

3. 核心功能架构

App 主要分为以下几个核心模块：

  • 登录/注册模块：支持验证码、密码登录，以及首次登录的资料完善。
  • 首页模块：展示用户的数字专辑柜/收藏，支持添加新专辑。
  • 识别添加模块：通过 NFC 感应或扫描二维码绑定实体专辑。
  • 专辑详情模块：数字专辑的核心消费场景，包含音乐播放、MV、写真、数字小卡、徽章展示及专属社区。
  • 消息通知模块：接收系统通知与社区互动消息。
  • 个人中心模块：管理个人资料、账号设置、问题反馈等。

4. 功能模块详细说明

4.1 登录与注册/找回密码

为提供更直观的交互体验，该模块已制作成高保真交互原型，请直接在下方操作体验：

功能说明：

  1. 本机号码一键登录：App 检测到本机号码后，作为首屏默认登录方式，一键快速认证。
  2. 验证码登录：用户输入手机号获取验证码进行快捷登录。
  3. 密码登录：老用户可使用手机号+密码进行登录。
  4. 第三方登录：支持微信、微博快捷授权登录。
  5. 首次登录设置：新用户首次通过验证码登录后，需设置登录密码，并进入资料完善流程（如设置昵称、头像、性别、生日等）。
  6. 找回密码：用户忘记密码时，可通过手机号验证码进行密码重置。
  7. 协议强校验：所有登录方式均要求勾选用户协议，未勾选时拦截并弹窗提示确认。

4.2 首页 (数字专辑柜)

功能说明：

  1. 专辑展示：以书架或列表形式展示用户已绑定/收藏的数字专辑。
  2. 空状态引导：当用户无收藏专辑时，展示缺省页并引导用户添加。
  3. 添加专辑入口：提供明显的“添加”按钮，点击后弹出添加方式选项（NFC 或 扫码）。
  4. 添加成功反馈：成功绑定新专辑后，首页需给出明确的视觉反馈与动效。

4.3 识别与添加模块

功能说明：

  1. NFC 识别：调用手机 NFC 功能，提示用户将手机靠近实体专辑内置的 NFC 芯片进行感应绑定。
  2. 扫码识别：调用相机权限，扫描实体专辑上的专属二维码进行绑定。
  3. 异常处理：若识别码无效、已被绑定或读取失败，弹出明确的错误提示。

4.4 专辑详情与消费模块 (核心)

本模块为 App 核心的数字内容消费与互动场景。分为以下几个子模块：

4.4.1 专辑主页

功能说明：
  • 展示专辑封面、简介、发售信息等基础资料。
  • 提供下拉或滑动交互，无缝切换查看专辑内的曲目列表、数字内容等。

4.4.2 音乐播放

功能说明：
  • 基础控制：包含播放、暂停、上一首、下一首、进度条拖动等标准播放器功能。
  • 歌词同步：支持查看与音乐进度同步滚动的动态歌词。
  • 播放列表：支持呼出当前专辑的曲目列表，快速切换播放歌曲。

4.4.3 专属 MV

功能说明：
  • 提供专辑附带的专属高清 MV 或幕后花絮视频播放。
  • 支持全屏播放、进度控制及音量/亮度调节。

4.4.4 数字写真

功能说明：
  • 以画册形式展示高清电子写真。
  • 支持左右滑动翻页，双指缩放查看高清细节，提供沉浸式视觉体验。

4.4.5 专属徽章

功能说明：
  • 徽章墙：集中展示该专辑专属的数字徽章。
  • 获取动效：用户绑定专辑或达成特定条件（如听歌时长、社区活跃等）时，弹出获取新徽章的专属动效。
  • 细节查看：支持点击放大查看徽章的高清3D/2D细节，以及获取时间、稀有度等信息。

4.4.6 数字小卡

功能说明：
  • 卡片收集：展示随实体专辑附赠的数字小卡，可采用固定获取或“盲盒抽卡”机制。
  • 获取动效：获得新卡片时展示专属的开卡动效，提升用户的惊喜感。
  • 细节交互：支持点击放大卡片，可能包含卡片翻转（查看背面签名或寄语）等交互设计。

4.4.7 专属社区

功能说明：
  • 专属权限：仅限拥有该数字专辑的用户进入的私密讨论区。
  • 互动功能：支持用户发布图文动态、评论、点赞，增强粉丝间的垂直社交与活跃度。

4.5 消息通知模块

功能说明：

  1. 消息列表：集中展示系统通知（如上新、活动）、互动消息（评论、点赞等）。
  2. 空状态：当没有消息时展示占位缺省图。

4.6 个人中心模块

功能说明：

  1. 未登录状态：展示默认头像与登录引导，限制部分功能的使用，点击触发登录提示。
  2. 个人资料管理：支持修改头像、昵称、性别、生日（调用日期选择器）等信息。
  3. 设置与账号管理：提供解绑设备/账号相关的操作及二次确认提示。
  4. 问题反馈：提供表单让用户提交使用过程中遇到的问题（支持文字描述、图片上传等），帮助优化产品。

5. 后续规划与建议

  • 数据埋点：建议在 NFC 识别成功率、核心页面停留时长、播放器使用率上做好数据埋点。
  • 性能优化：由于包含大量高清写真、小卡及音频视频内容，需做好缓存管理和加载优化，避免占用过多手机存储。
